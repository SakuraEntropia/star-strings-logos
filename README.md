# 来自星星的弦乐 / Strings from the Stars

为同人短篇绘制的三款蓝紫色折线标题。字形为可编辑 SVG 路径，带白色描边与投影；无需安装字体。

| 版本 | 文件 |
| --- | --- |
| 日文：スターストリングスより | [star-strings-ja.svg](star-strings-ja.svg) |
| 中文：来自星星的弦乐 | [star-strings-zh.svg](star-strings-zh.svg) |
| 英文：STRINGS FROM THE STARS | [star-strings-en.svg](star-strings-en.svg) |

三款 SVG 可从 [star-strings-logos-svg.zip](star-strings-logos-svg.zip) 一次下载。中文标题排为「来自星星／的弦乐」两行。

`build_hand_drawn.py` 是生成源文件；重新运行需要 Python、fontTools 及 macOS 的 Avenir Next 字体。发布的 SVG 文件独立可用。

这是同人创作，非《来自深渊》官方标识。
